# Plan: Sub-agent Monitoring & Steering

**Date:** 2026-07-22
**Status:** Approved
**Estimate:** ~170 baris, 4 file diubah, 1 file baru

---

## Problem

User tidak bisa melihat output real-time sub-agent (monitoring) dan tidak bisa menginterupsi sub-agent yang salah arah (steering).

### Monitoring
- Sekarang hanya lihat tool name di TUI widget
- Tidak bisa lihat: thinking/reasoning sub-agent, streaming text reply, tool output (bash, file read)

### Steering
- Sub-agent jalan async, user baru tahu salah arah setelah selesai
- Tidak ada cara interupsi mid-turn

---

## Solusi

Memanfaatkan SDK Pi yang sudah ada:
- `session.subscribe()` — menangkap event `message_update`, `tool_execution_update`, dll
- `session.steer()` — interrupt mid-turn

**Zero SQLite.** Semua transcript in-memory.

### Step 2: `slices/spawn/spawn.manager.ts` (+30 baris)

Di subscribe callback (line 228), tambah handler transcript:

```typescript
// helper + cap
const MAX_TRANSCRIPT = 200;
function pushTranscript(handle, entry) {
  if (!handle._transcript) handle._transcript = [];
  if (handle._transcript.length >= MAX_TRANSCRIPT) handle._transcript.shift();
  handle._transcript.push(entry);
}

// Di dalam subscribe callback:

// text delta — coalesce ke entry terakhir
if (event.type === "message_update" && event.assistantMessageEvent?.type === "text_delta") {
  const last = handle._transcript?.[handle._transcript.length - 1];
  if (last?.type === "text") { last.content += event.assistantMessageEvent.delta; }
  else { pushTranscript(handle, { type: "text", content: event.assistantMessageEvent.delta, timestamp: Date.now() }); }
}

// thinking delta — coalesce
if (event.type === "message_update" && event.assistantMessageEvent?.type === "thinking_delta") {
  const last = handle._transcript?.[handle._transcript.length - 1];
  if (last?.type === "thinking") { last.content += event.assistantMessageEvent.delta; }
  else { pushTranscript(handle, { type: "thinking", content: event.assistantMessageEvent.delta, timestamp: Date.now() }); }
}

// tool output
if (event.type === "tool_execution_update" && event.output) {
  pushTranscript(handle, { type: "tool_output", content: event.output, timestamp: Date.now(), toolName: event.toolName });
}

// tool result
if (event.type === "tool_execution_end") {
  const result = typeof event.result === "string" ? event.result : JSON.stringify(event.result ?? "");
  pushTranscript(handle, { type: "tool_result", content: result, timestamp: Date.now(), toolName: event.toolName, isError: event.isError });
}
```

### Step 3: `slices/spawn/spawn.monitor.ts` (FILE BARU, ~130 baris)

Dua tool:

**`crew_log`** — baca transcript sub-agent:
- Input: `subagent_id`, `limit?` (default 10)
- Validasi ownership via `validateOwnership()` dari `lifecycle.shared.ts`
- Ambil N entry terakhir dari `handle._transcript`
- Output: status, turns, total entries, tiap entry truncated 200 chars
- Fallback: "belum memulai aktivitas" kalo transcript kosong

**`crew_inject`** — interupsi sub-agent mid-turn:
- Input: `subagent_id`, `message`
- Validasi ownership + status guard (`running`/`spawned` only)
- Panggil `handle.session.steer(message)`
- Log steer ke transcript untuk audit trail
- try/catch, error handling

## Risiko & Mitigasi

| Risiko | Mitigasi |
|--------|----------|
| Transcript memory leak | Cap 200 entries, shift oldest. Coalesce text/thinking deltas (bukan 1 entry per delta) |
| `session.steer()` gagal | Status guard + try/catch |
| Concurrent append | JS event loop single-threaded, no race |
| Event shape berubah | Guard dengan `&&` checks |

---

## SDK APIs Used

| API | Source | Fungsi |
|-----|--------|--------|
| `session.subscribe(event)` | Pi SDK (sudah dipakai) | Transcript collection |
| `session.steer(text)` | Pi SDK — `steer(text: string): Promise<void>` | Mid-turn interupsi |
| `validateOwnership()` | `lifecycle.shared.ts` (milik sendiri) | Ownership validation |
| `Type.Object()` / `Type.String()` | TypeBox | Tool parameter schema |
