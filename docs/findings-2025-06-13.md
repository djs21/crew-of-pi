## Detail Per Temuan

### 1. spawn.renderer.ts — Dead Code
File mengekspor 3 fungsi (formatUsageStats, getStatusIcon, getStatusLabel) tapi tidak ada yang meng-import. Fungsi di-duplikasi di widget.renderer.ts.
Fix: Hapus file.

### 2. DEFAULT_BLOCK_POLICY Duplikasi
shared/types.ts punya BlockPolicy (string[]), blockers.types.ts punya BlockPolicyConfig (BlockedToolConfig[]). Yang kedua yang dipakai.
Fix: Hapus BlockPolicy dari shared/types.ts.

### 3. blockers.policy.ts — Dead Code
4 fungsi tidak dipanggil: createBlockPolicy, addBlockedTool, removeBlockedTool, getBlockedToolsDescription.
Fix: Hapus file.

### 4. comms.persistence.ts — 3/4 Dead
persistBusState (tidak dipanggil), restoreBusState (stub), loadPersistedMessages (tidak dipanggil). Hanya persistMessage yang dipakai.
Fix: Implement restoreBusState via ctx.sessionManager.getEntries(), wire di session_start, hapus persistBusState, konsisten pakai persistMessage di comms.relay.ts.

### 5. crew_list Inline
Tool crew_list 50 baris di index.ts, sementara 5 tool lain punya slice sendiri.
Fix: Extract ke slices/crew-list/crew-list.tool.ts.

### 6. Widget Emoji Inkonsisten
spawn.renderer.ts: 🟢, widget.renderer.ts: ⏳.
Fix: Ter-resolve setelah spawn.renderer.ts dihapus.

### 7. Session Restore
session_start tidak me-restore message bus. Pesan crew-bus-message tidak dibaca ulang.
Fix: restoreBusState scan entries + injectHistory() ke bus.

### 8. Interactive Stdin
crew_respond tulis ke bus tapi stdio: ["ignore",...] — subagent tidak terima.
Fix: Pipe stdin untuk interactive, simpan proc di handle, tulis JSON ke stdin.

### 9. Config Loader
crew-of-pi.json didokumentasikan di README tapi tidak diimplementasi.
Fix: agents.config.ts — load global + project, merge override (project > global), apply ke AgentConfig.

### 10. Testing
Tidak ada test file. Di-skip — effort mock child_process.spawn + pi SDK besar, project sudah stabil di production.
